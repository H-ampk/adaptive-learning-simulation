# 生成学習者モデル

生成学習者モデル（Generative Learner）は、シミュレーション上の世界です。練習、知識の変化、観測される回答を生み出します。評価対象のモデル（BKT、PFA、HLR など）は、その世界に適合させるか、その世界に対して採点します。世界そのものを定義するのは、評価対象のモデルではありません。

## 設計原則

- BKT、PFA、HLR のいずれも、真のデータ生成モデルとしては使わない。
- 評価対象のモデルと生成世界は、独立したままにする。
- 頑健性は複数の世界にわたって見る。結果が一つの学習仮定の産物にならないようにするためである。

一つの世界は、学習の規則、忘却（Forgetting）の規則、時間を明示するかどうかを述べます。それらの仮定を変えることは、世界を変えることです。採点されるモデルの隠れたパラメータを変えることではありません。

## 世界

### World A — 学習のみ（Learning-only）

最小のベースライン（Baseline）です。

- 学習はある
- 忘却はない
- 間隔効果（spacing effect）はない

World A は、知識の変化が練習による学習だけのときにも、伝播のパターンがすでに現れるかを確認します。

### World B-E — 指数忘却（Exponential Forgetting）

主分析の候補です。

- 逓減する学習
- 指数忘却
- 明示的な時間

忘却更新の候補：

```text
K(t + Δ) = K(t) exp(-λ Δ)
```

この式は、忘却の段階の候補です。世界の仕様全体ではありません。学習の段階、`Δ` の分布、パラメータは未確定です。

### World B-P — べき乗忘却（Power-law Forgetting）

主分析の候補です。

- 逓減する学習
- べき乗忘却
- 明示的な時間

忘却更新の候補：

```text
K(t + Δ) = K(t) (1 + λ Δ)^(-β)
```

World B-E と World B-P は、人間の記憶にとってどちらの忘却曲線が正しいかの順位付けではありません。両方を走らせるのは、伝播の結果が忘却の族に依存するかを問うためです。

### World C — 認知的・間隔のストレステスト（Cognitive / Spacing Stress Test）

式が決まるまでは、主分析の世界ではなくストレステストです。

- 練習履歴への依存
- 活性化（activation）または痕跡（trace）に基づく状態
- より明示的な間隔効果
- Pavlik–Anderson および ACT-R 系の間隔モデルを参考にする

World C の式は固定していません。式を採用するには、内部状態、活性化または痕跡の更新、その状態から canonical な `K` をどう導出するかを書いた、別の設計メモが必要です。導出の確定は Issue #11 の範囲です。

World C は activation や memory trace など、`K` 以外の内部状態を保持してよい。World 間比較のため、外部から取得可能な canonical latent competence として `K ∈ [0,1]` を提供する。

## 潜在状態

確定した正本は、生成学習者の学習者 `u`、概念 `c`、時刻 `t` に対する真の潜在状態

```text
K[u, c, t] ∈ [0, 1]
```

である。`K` は連続的な潜在コンピテンス・保持状態である。

`K` は BKT の `P(L)` ではない。`P(L)` は二値の learned / unlearned 状態に対する mastery probability であり、この `K` と同一視しない。BKT、PFA、HLR のいずれかの内部状態も真値としては採用しない。

派生値は

```text
a = logit(K)
```

である。`a` は保存状態ではない。問題難易度との回答確率計算に使うとき、必要に応じて計算する。

`a ∈ ℝ` を全 World 共通の保存状態とする案は採用しない。現在候補となっている学習・忘却式は `K` 空間で自然に定義される。学習・忘却のたびに `a → K → a` へ往復すると、更新のたびに変換が増える。mastery と retention の解釈も `K` より間接になる。`a` や activation 形式そのものは否定しない。World C 等の内部状態として使う余地は残す。

採用理由は次である。

- World A / B-E / B-P の学習と忘却を、同じ有界な状態空間で表せる。
- Mastery threshold を `[0, 1]` 上で直感的に定義しやすい。
- `a = logit(K)` により、問題難易度と同じ logit 尺度へ接続できる。
- 標準難易度 `d = 0` では、基礎正答確率が `K` と一致する。
- BKT / PFA / HLR のいずれかの内部状態を真値として採用せずに済む。

## 回答モデル

Guess / Slip を含む最終的な回答生成式は未確定である。確定は Issue #2 の範囲であり、ここでは回答モデル全体を固定しない。

問題難易度 `d` は実数の logit 尺度に置く。基礎正答確率の候補は

```text
p_base = sigmoid(logit(K) - d)
```

である。`d = 0` のとき `p_base = K` となる。これを状態尺度の解釈上の基準とする。

`logit(0)` と `logit(1)` を避けるため、logit 変換の直前だけ

```text
K_safe = clamp(K, ε, 1 - ε)
```

を使う。この clamp は保存されている真の `K` を変更しない。`ε` は学習・忘却モデルの研究パラメータではなく、数値計算上の安定化定数である。具体的な実装値は実装 Issue で決めてよい。

Guess / Slip を含む正答確率の有力候補は、これまでどおり次である。この式は未確定の候補である。

```text
P(correct) = G + (1 - G - S) * sigmoid(a - d)
```

ここで `a = logit(K)` であり、

- `G` は当て推量（Guess）
- `S` はうっかり誤答（Slip / Lapse）
- `d` は問題難易度（Item Difficulty）

である。パラメータの値、事前分布、`G` と `S` が問題ごとまたは学習者ごとに変わるかどうかは、未設定である。

## 学習と忘却の更新空間

World A / B-E / B-P の主たる学習状態更新は `K` 空間で行う。具体的な learning update 式と Learning Rate は Issue #4 で確定する。

World B-E / B-P の忘却更新も `K` 空間で行う。指数忘却・べき乗忘却の式とパラメータは Issue #6 / #7 で確定する。上に書いた忘却式は、その空間で書く候補であり、確定した式ではない。

## 学習増分

知識の更新には逓減する利得を使います。際限なく加算する利得は候補にしません。次の例は `K` 空間の候補であり、確定した learning update ではありません。

例：

```text
K+ = K + L (1 - K)
```

`L` は、この例では `(0, 1]` の学習率の項です。履歴、時間、現在の問題への依存は世界ごとに異なり、まだ固定していません。

主たる世界では、学習増分（Learning Gain）を、回答が正しかったか誤りだったかから直接取りません。基本の因果は次です。

```text
practice opportunity → learning
```

日本語では「練習の機会 → 学習」です。

練習の機会が知識を更新します。観測された正誤は回答モデルの出力であり、増分を決める入力ではありません。

次は感度分析（Sensitivity Analysis）であり、主たる世界からは分けておきます。

- 検索に成功したときの上乗せ（successful retrieval bonus）
- 誤答にフィードバックが付く場合（incorrect response plus feedback）
- その他の、正誤に依存する学習規則（correctness-dependent learning rules）

感度分析用の世界は、これらの修飾のどれを加えるかを述べます。ラベルなしに、主たる推定と混ぜません。

## 実装との関係

正式な研究実装の言語は Julia である。依存関係はリポジトリ直下の `Project.toml` と `Manifest.toml` で固定する。生成学習者の Julia 実装は、この文書の時点ではまだ置いていない。

`src/als/generative/` は過去の Python 試作である。正式実装ではない。試作内の `ConceptState.ability` を保存値とする対応は、今回確定した正本 `K` と一致しない。試作の削除や書き換えは別 Issue の範囲であり、この文書の決定ではコードを変更しない。

確定した状態の対応は次である。

| 研究上の量 | 扱い |
| --- | --- |
| `K[u, c, t] ∈ [0, 1]` | 保存する真の潜在状態 |
| `a = logit(K)` | 保存しない派生値。回答確率の計算時に使う |
| `d` | 問題難易度。logit 尺度の実数 |
| `K_safe = clamp(K, ε, 1 - ε)` | logit 直前だけの数値安定化。保存する `K` は変えない |
